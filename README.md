# Glyph

Glyph is a Typora-style Markdown editor for Windows by ChillCode. You edit Markdown live in a WYSIWYG view, and Glyph saves your files faithfully: an unchanged document is written back byte for byte, and after an edit only the changed blocks are rewritten.

Highlights:

- Live editing of headings, lists, task lists, GFM tables, syntax-highlighted code blocks, images and LaTeX formulas.
- Tabs, a second pane and a Source + Live view.
- Folder sidebar with file tree and document outline.
- Light, dark or system theme; German, English and Arabic interface.
- Export to standalone HTML and to PDF.

## Download

Get the latest installer from the **[Releases page](https://github.com/ChillCodeForge/Glyph/releases/latest)**. Download `Glyph_<version>_x64-setup.exe` and run it. Every release lists the SHA-256 checksum of the installer in `SHA256SUMS.txt`.

## Source code

Glyph is closed source. This repository only publishes release binaries; it contains no source code and does not accept pull requests.

## Reporting problems

Found a bug or have a suggestion? Open an [issue](https://github.com/ChillCodeForge/Glyph/issues). Please include the Glyph version (part of the installer file name), your Windows version, and the steps that lead to the problem.
